# Fluxo de Trabalho: Evoluir (ID 100)

> **Classificação do Integrador:**
> - **ID Integrador / Convênio:** `100`
> - **Tipo de Operação:** `agendamento`
> - **Tipo de Processamento Padrão:** `local` / `server`
> - **Alocação no Worker:** Servidores Exclusivos de Agendamento (Portas 9005 e 9006)

## Objetivo
O integrador Evoluir é responsável pelo processamento de pacientes, detalhes de atendimento, PTS (Planos Terapêuticos), corpo clínico e relatórios da clínica.

## Operações Suportadas
- **OP1:** Extração de Pacientes e Agendamentos.
- **OP2:** Detalhamento de Atendimentos.
- **OP3:** Planos Terapêuticos Singulares (PTS).
- **OP5:** Mapeamento de Corpo Clínico.
- **OP6:** Baixa de Atendimentos Faturados.
- **OP7:** Download de Documentos Terapêuticos.
